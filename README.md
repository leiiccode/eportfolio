# Portfolio

A React and Vite portfolio site showcasing Francis Pascua's profile and services.

## Deployment

Deploy this repository with Vercel using the repository root as the **Root Directory**. The root `vercel.json` configures the Vite build and `dist` output.

## Local development

Run `npm run dev` to start the local development server.

Run `npm run build` to create a production build and `npm run lint` to check the source files.
